# Machine Agent v0.2.0

This release adds the host-side execution required by Smart Machine
Orchestration. It remains intended for authorized development and test
servers, not production deployment.

## Highlights

- read-only host discovery before any managed mutation;
- deterministic TCP/UDP preferred and fallback port selection;
- one bounded retry when a selected port races during container creation;
- protocol-level failure isolation so healthy sibling nodes can continue;
- explicit ownership checks for Docker containers, networks, certificates,
  WARP, and rollback operations;
- Debian 12/13 and Ubuntu 22.04/24.04 support on amd64 and arm64;
- resumable, idempotent enrollment and existing-credential upgrades.

External Docker and WARP installations are not silently adopted or modified.
An incompatible external WARP runtime requires an explicit, audited takeover
authorization, and resources without positive myRemnawave ownership are left
untouched.

## Install or upgrade

Use the one-time command generated by the panel's Machine wizard. The installer
downloads immutable `v0.2.0` release assets and verifies `SHA256SUMS` before
replacing the Agent binary or service definition.

## Remaining acceptance work

Real 3X-UI before/after fingerprint comparison, protocol data-plane testing,
HTTP-01 certificate issuance, and WARP routing verification remain test-server
acceptance gates. The implemented safety checks fail closed when ownership or
resource availability cannot be established.
